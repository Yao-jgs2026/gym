数据备份与恢复

数据保存在本机浏览器中，清理浏览器缓存、更换电脑或浏览器会导致数据全部丢失。建议每周导出一次备份文件存到网盘或U盘。
导错了文件也不用慌：系统会自动留存「导入前」的数据，点 ↩️ 恢复导入前的数据 就能一键还原。

☁️ 云同步（多设备共享同一份数据）

开启后，店里、你的电脑、手机都读写同一份数据：谁签到一个会员，所有设备立刻能看到。
推荐用 GitHub 存档：永久免费、不收一分钱、没有到期时间，只需注册一个免费账号。

同步通道：

Token 只保存在这台设备的浏览器里，不会上传到任何地方；每台设备都要填一次（存档ID 填同一个）。

需要先在控制台开启「匿名登录」，并把当前网址加入 Web 安全域名。
